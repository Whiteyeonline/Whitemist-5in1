# ⚡ Multi-Job Intelligence & Web Audit Engine

A 100% free, professional-grade web performance, lead generation, trademark analysis, and OSINT footprint platform powered by Python, Streamlit, and Google Gemini.

## 🧰 Included Modules (5 Sub-Jobs)

1. **Technical & SSL Web Audit:** 5-point automated security, SSL, mobile responsiveness, and Core Web Vitals audit.
2. **B2B Lead Generation:** Scrapes public corporate emails, phone numbers, and direct social profiles from any domain.
3. **Competitor Benchmarking:** Runs dual Google PageSpeed Insights evaluations and plots side-by-side performance charts.
4. **Global Trademark Checker:** Searches WIPO, USPTO, and EUIPO trademark data and outputs dual reports (Kid-friendly + Professional legal specs).
5. **OSINT Life History & Footprint:** Reconstructs full birth-to-now narrative timelines, wins, losses, and major incidents for any person or company.
